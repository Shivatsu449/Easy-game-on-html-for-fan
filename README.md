# 🏁 Пиксельные гонки

Небольшая аркадная игра для браузера: управляйте красной машиной, обходите синие автомобили и набирайте очки на городской трассе.

Написана на **HTML, CSS и JavaScript**, отрисовка — через **Canvas 2D**. Работает без сборки, внешних библиотек и подключения к серверу.

## Быстрый запуск

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте `index.html` двойным щелчком в браузере.

Устанавливать Docker, Node.js или другие программы для запуска не нужно. Все необходимые файлы находятся в проекте. Для игры нужна клавиатура; экранных кнопок для телефона в текущей версии нет.

## Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `W` — удерживать | Ускорение |
| `R` | Перезапуск после столкновения |

## Правила игры

- Объезжайте синие машины, не сталкиваясь с ними.
- За каждый автомобиль, ушедший за нижний край экрана, начисляется одно очко.
- Столкновение завершает заезд и запускает эффект взрыва.
- После проигрыша нажмите `R`: счёт и скорость сбросятся, начнётся новый заезд.

## Играть по ссылке через GitHub Pages

После загрузки проекта в репозиторий:

1. Убедитесь, что `index.html`, `style.css` и `game.js` находятся в корне репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку с проектом, например `main`, и папку **/ (root)**. Нажмите **Save**.
5. Дождитесь публикации: ссылка появится на этой же странице.

После публикации игру можно открыть по ссылке в браузере. Отдельный сервер и Docker не требуются.

Официальная инструкция: [настройка источника публикации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Текущие особенности

Игра рассчитана на управление с клавиатуры. Поле имеет размер 480 × 640 пикселей; на маленьких экранах оно может не помещаться целиком. Скорость движения зависит от частоты кадров. Счёт хранится только в текущем заезде и не сохраняется после закрытия страницы.
